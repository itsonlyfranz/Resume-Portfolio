Human-in-the-Loop Approval Agent decides on refund requests only when it is sure. When it is not, it pauses, asks a human a specific question, validates the answer, and resumes, with every step written to a tamper-evident audit log.

## Architecture

- **agent.py** is the LangGraph `StateGraph` with typed `AgentState`, 10 nodes, conditional edges, `interrupt` and a SQLite checkpointer, with `ApprovalAgent.submit` and `resume` wrapping it.
- **uncertainty.py** prompts the model, parses its JSON assessment, and turns results and failures into pause signals.
- **store.py** keeps the local-file ticket index, written atomically, that a reviewer queue shows, while the graph checkpoint holds run state.
- **validation.py** checks authority, separation of duties, completeness and amounts on human responses.
- **executor.py** is an idempotent ledger standing in for the side-effecting payments call.
- **audit.py** is the append-only hash-chained JSONL log with verification, and **cli.py** exposes `hitl demo | submit | pending | respond | audit`.
- **llm.py** defines the `LLMClient` interface with `AnthropicClient` and an offline `FakeLLMClient`.
