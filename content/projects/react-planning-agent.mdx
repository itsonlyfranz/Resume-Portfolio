ReAct Planning Agent is an observe, think, act, reflect agent that is bounded on every axis: it can't loop forever, it critiques its own answers, and when it has to stop early it degrades gracefully instead of crashing.

## Architecture

- **ReActAgent (agent.py)** builds and runs the LangGraph `StateGraph`; the `gate` node enforces the iteration cap and deadline, and `act` enforces repeat-call and error-streak limits.
- **LangGraph runtime** checkpoints every super-step per `thread_id` with `MemorySaver`, with `recursion_limit` as a second-line backstop that degrades from the last checkpoint.
- **ToolRegistry (tools.py)** dispatches tools and turns unknown tools, bad arguments and crashes into observations, shipping a safe AST calculator and a local fact lookup.
- **LLMClient / AnthropicClient (llm.py)** is a one-method provider interface for Claude, while `ScriptedLLM` (fake.py) replays responses offline and can simulate outages or a stuck model.
- **parsing.py** and **models.py** handle tolerant JSON extraction, Pydantic validation, and typed models such as `AgentConfig`, `RunResult` and `StopReason`.
- **trace.py** appends each run to a local JSONL file.
