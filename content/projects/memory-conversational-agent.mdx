Memory-Enabled Conversational Agent is a LangGraph agent that remembers its users: a token-budgeted short-term buffer, long-term vector recall, LLM-driven context compression, and a multi-signal relevance scorer, all running on local files with Claude as the model and no external services.

## Architecture

- **Turn graph (graph.py)** is a `StateGraph` over a typed `TurnState` with nodes `recall`, `generate`, `update_buffer` and `extract` running in parallel, and `store`.
- **MemoryAgent / ChatSession (agent.py)** wraps the graph with a thread id per user and session, and writes an episodic summary on `close()`.
- **ShortTermBuffer (buffer.py)** and **ContextCompressor (compression.py)** fold old turns into an LLM-written summary under a token cap, with an extractive fallback if the model fails.
- **MemoryExtractor (extraction.py)** and **LongTermMemory (memory.py)** extract durable facts, then embed, deduplicate, supersede by slot, recall, reinforce, forget and evict, strictly per user.
- **RelevanceScorer (scoring.py)** blends similarity, recency, importance and frequency, and **HashingEmbedder (embeddings.py)** provides local deterministic embeddings behind an `Embedder` protocol.
- **JsonlMemoryStore (store.py)** persists memory under `flock` with compaction, and a SQLite checkpointer resumes each session's buffer.
