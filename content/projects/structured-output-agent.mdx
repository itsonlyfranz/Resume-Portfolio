Structured Output Agent is an agent harness for making LLMs reliable instead of random: model output is forced into Pydantic schemas, every tool call and tool result is validated, and each failure is retried with targeted feedback and recorded in an audit log.

## Architecture

- **graph.py** is the LangGraph `StateGraph` shared by both entry points, with nodes `generate`, `validate`, `act` and `fail`, conditional edges for retry, tool execution and budget exhaustion, and optional checkpointing per run id.
- **runner.py** provides `StructuredRunner`, the no-tools graph, where failures become corrective user messages naming the offending fields.
- **agent.py** provides `ToolAgent`, the graph with an `act` node where each turn is a `call_tool` or `final` step, bounded by a step budget so a tool call beyond the budget is never executed.
- **tools.py** holds `Tool` and `ToolRegistry` with Pydantic input and output models that validate arguments, execute, then validate results.
- **failures.py** keeps `ValidationFailureLog`, the in-memory and append-only JSONL audit trail.
- **llm.py** defines the one-method `LLMClient` protocol with `AnthropicClient` (Claude via LangChain) as the only provider seam, while `testing.py` supplies an offline `FakeClient`.
